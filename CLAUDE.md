# 8. Scroll-Driven Flight Experience

Use GSAP and ScrollTrigger to create a master scroll-driven animation timeline.

The jet must move through the entire journey as the visitor scrolls.

Suggested normalized timeline:

| Scroll progress | Chapter                  |
| --------------- | ------------------------ |
| 0–8%            | Opening and takeoff      |
| 8–22%           | Chapter 01               |
| 22–38%          | Chapter 02               |
| 38–51%          | Chapter 03               |
| 51–65%          | Chapter 04               |
| 65–84%          | Chapter 05               |
| 84–100%         | Chapter 06 and final CTA |

Normalized flight progress from 0 to 1 must control:

- Aircraft position.
- Aircraft orientation.
- Banking and pitch.
- Camera position and rotation.
- Environmental transitions.
- Chapter visibility.
- Milestone card visibility.
- HUD information.
- Waypoint markers.

All animation must be deterministic and reversible.

Scrolling backward must correctly reverse the entire experience.

Avoid using React state updates on every animation frame. Use appropriate Three.js and GSAP animation mechanisms.

Performance is a major priority.

- Optimized GLB models.

- Reusable geometries and materials.
